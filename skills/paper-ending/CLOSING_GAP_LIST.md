# Closing gap list (reference)

Use when the paper-ending entry gate fails: the required venue brief is missing or shortlist selection is pending, the body is incomplete, the contribution block is missing or stale, or any required closing claim lacks an author-confirmed ID, resolvable real support, or scope within the support. Return this list instead of affirmative closing prose.

For each failed claim:

1. Identify the proposed claim.
2. State what material is missing.
3. If existing material supports a narrower claim, propose it for author confirmation.

Emit no affirmative closing prose while its entry gate fails. The blocked
closing resumes when the author supplies a ready brief or confirms adequate
material, as applicable.
