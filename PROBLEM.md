# About this md
Este es un md con el objetivo de definir por el usuario el problema subyacente para ser analizado y documentado en los documentos oficiales del proyecto.

# Problema
Los coding agents asisten cada vez más la escritura de papers de CS, pero lo hacen sin una
metodología de comunicación: el resultado suele ser texto correcto pero mal estructurado y
poco claro. No existe un conjunto portable de skills/herramientas que codifique los
principios de comunicación científica de "Make It Clear" (Winston) para que cualquier
harness (Claude Code, OpenCode, Codex) los aplique al escribir, editar y evaluar papers.

# Objetivo
Derivar de la metodología de Winston (síntesis propia, no extracción literal) un skill set
+ herramientas, en formato SKILL.md estándar con integración por harness, validado contra
una rúbrica basada en los principios del libro.

# Que entregar

1. set de SKILL.md (skill set + herramientas que usan)
2. Rúbrica de evaluación de papers (basada en los principios de Winston)

# Que no entregar



1. Código de herramientas (se asume que ya existe)
2. Código de harness (se asume que ya existe)

# Alcance

1. Solo papers de Computer Science
2. No se cubre papers de otras areas no derivadas de Computer Science
3. No Libros 
4. No presentaciones
5. Figuras dentro de papers
